# Internationalization

Yuli Todo is an **English-native** product. Simplified Chinese is a supported UI language.

## Policy

| Layer | Language |
| --- | --- |
| Repository docs | English |
| Code, file names, identifiers, enum values | English |
| Source UI strings | English (`en`) |
| Translated UI strings | Simplified Chinese (`zh-CN`) |
| User data (task names, types, tags, content, notes) | Stored exactly as typed; never auto-translated |

Identifiers such as `will_do`, `board_column`, `theme_id`, and `tiktok` are never localized.

## Locale ids

- `en` — default, source of truth for copy
- `zh-CN` — complete translation of chrome, buttons, dialogs, empty states, settings labels, status chips

No other locales in v1. Missing `zh-CN` keys must fall back to `en` in development builds and must be treated as a bug before release.

## Runtime

- The current locale is `settings.locale`.
- Changing it in Settings re-renders chrome immediately. It does not rewrite the database.
- Date and time **display** follows the locale:
  - `en`: `YYYY-MM-DD HH:mm` (24-hour in v1 for consistency)
  - `zh-CN`: `YYYY-MM-DD HH:mm` is acceptable; `YYYY年M月D日 HH:mm` is preferred
- The datetime **picker** still edits local wall time at minute precision regardless of locale.

Message format: ICU-style or equivalent (`{name}` placeholders). Do not concatenate translated fragments.

Catalogs for the implementation phase (not created in this design phase):

```
locales/en.json
locales/zh-CN.json
```

Load them with the in-app helper in [architecture.md](architecture.md) (Vite import, English fallback). Do not add i18next.

Keys are dotted English paths, for example `board.column.todo`, `dialog.done.title`.

## Duration format

Format `doing_elapsed_seconds` for display. Omit zero units except when the whole value is under one minute.

| Elapsed | `en` | `zh-CN` |
| --- | --- | --- |
| 0–59 seconds | `0m` | `0分` |
| 1–59 minutes | `{m}m` | `{m}分` |
| Hours, no extra minutes | `{h}h` | `{h}小时` |
| Hours and minutes | `{h}h {m}m` | `{h}小时{m}分` |
| Days plus remaining hours/minutes | `{d}d {h}h {m}m` (drop zero `h`/`m` segments) | `{d}天{h}小时{m}分` (同样省略为零的段) |

Examples: `45m` / `45分`; `2h` / `2小时`; `2h 3m` / `2小时3分`; `1d 4h` / `1天4小时`.

Do not show seconds. Round **down** to whole minutes after converting from stored seconds.

## Implementation notes

- Keep `en.json` and `zh-CN.json` in the same PR whenever chrome copy changes.
- Do not ship mixed-language chrome (English buttons on a Chinese page) except user content.
- Error screens that appear before settings load use `en`, then re-render if a saved locale is read successfully.
